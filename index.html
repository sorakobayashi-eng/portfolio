Process

制作の流れ

生成AIの動画は、この順番で作っています。作る工程の前後に、確かめる工程を必ず入れています。

01020304050607
A1確かめる

参考を分析

伸びている投稿を1秒ずつ見て、構成表にしてから台本に入ります。

商品を理解

部品・使い方・注意書きを確認し、実物と合う使い方で見せます。

検品

薬機法の NG 表現を辞書で機械チェック。語りは文字起こしで原稿と照合し、全カットを目で確認します。

投稿後の分析

再生数・売上・コメントを集め、伸びた理由を次の型にします。

V1つくる

構成と台本

つかみと見せ場の順番を決め、テロップと台詞を書きます。

生成

画像を作ってから動画に。顔と服がそろうよう元の絵を固定します。

編集・組み立て

声・テロップ・音を組みます。組み立てと書き出しは Claude Code で自動化。
